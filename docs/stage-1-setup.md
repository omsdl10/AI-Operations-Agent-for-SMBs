# Stage 1 Setup

Stage 1 creates the monorepo foundation:

- React + TypeScript frontend with Tailwind CSS, React Router, Axios, ESLint, and Prettier.
- FastAPI backend with modular folders, environment configuration, database configuration, logging, API versioning, and health checks.
- Docker Compose with PostgreSQL, Redis, frontend, and backend services.
- Shared environment template and setup documentation.

Future stages will add authentication, database models, dashboard screens, CRM workflows, Twilio, LangGraph agents, automation workers, and daily summaries.
