# Stage 5 React Dashboard

Stage 5 adds the SaaS dashboard interface:

- Responsive sidebar and top navigation.
- Protected pages for Dashboard, Customers, Leads, Messages, Invoices, Appointments, Settings, and System Health.
- Dashboard widgets for leads, unread WhatsApp messages, follow-ups, overdue invoices, appointments, revenue, and AI activity.
- Loading and error states for dashboard data.
- Reusable UI components for page headers, stat cards, status badges, and table shells.
- Mock dashboard data for the MVP frontend while API modules are built in later stages.

The CRM and messaging pages are intentionally read-only in this stage. Full create, update, delete, search, filter, and pagination workflows are part of Stage 6 and later stages.
